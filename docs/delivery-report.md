# Отчёт о поставке KEPIL

1. **Исходное состояние:** пустая папка, без package.json, Git, приложения, БД и env.
2. **Изменения:** реализован код Next.js MVP: экраны, серверные действия, SQL/RLS, миграции, тесты, seed и документация. Живое облачное демо ещё не запущено.
3. **Архитектура:** Next.js App Router / TypeScript → Supabase Auth → серверная валидация → PostgreSQL RPC/RLS → приватный Storage.
4. **Таблицы:** все 13 сущностей ТЗ, служебная private.settings, представление claims_overview. Полный перечень в README.
5. **Бизнес-правила:** гарантия, подрядчик, повторяемость, SLA, переходы, приёмка/возврат, доказательства и аудит реализованы и испытаны SQL-тестами.
6. **API:** Server Actions для входа/выхода, дефекта, статуса, фото, реестра, уведомлений; /api/health без выдачи секретов.
7. **Auth/RBAC:** Supabase SSR, проверка пользователя и профиля, RLS, запрет прямых клиентских изменений, изоляция подрядчиков. Облачный Auth ещё не испытан.
8. **Тесты:** 24 теста: 24 passed, 0 failed, 0 skipped; npm test exit 0. Есть полный цикл под authenticated, включая изоляцию файлов. Регрессия старого фото после отказа воспроизведена и исправлена.
9. **Финальные проверки 25 сентября:** npm run lint — 0 ошибок и предупреждений, exit 0; npm run typecheck — exit 0; npm run build — exit 0, Next.js 16.3.6, все 16 маршрутов собраны. Browser QA не выполнен: инструмент вернул пустой список браузеров.
10. **Демо:** точный пошаговый сценарий в README. Для живого показа сначала нужны миграция и seed в выбранной базе.
11. **Аккаунты:** пять email в README; создаются seed. Пароль задаётся DEMO_PASSWORD, готовых облачных аккаунтов нет.
12. **Env:** URL и publishable key для приложения; service-role key и DEMO_PASSWORD исключительно для seed.
13. **Реальное/демо:** SQL-процессы, роли и хранение реализованы реально; исторические записи и начальные иллюстрации явно демонстрационные. Mock-режима приложения и localStorage-БД нет.
14. **Ограничения:** нет внешних госинтеграций, фоновых рассылок, realtime, UI управления аккаунтами; облачное наполнение/Storage и браузерный demo ещё не проверены. Детали в README.
15. **Deployment:** локальный сервер http://localhost:3000 работает с экраном настройки. Новый Supabase ожидает выбора организации. Vercel авторизован как nerfalmiralti-5552, но публикация отклонена автоматическим контролем разрешений. Публичной работающей версии пока нет.

Независимый ревьюер проверил SQL/RLS и основной процесс. Найденный обход свежести доказательства устранён; дополнена история статусов дефекта.

16. **При возобновлении:** существовали все основные экраны, схема и 16 проходивших тестов. Сохранены архитектура и работающий код. Не хватало крайних случаев гарантий, полноценной проверки файлов и облачного запуска.
17. **Доработано сейчас:** PostgreSQL-представление warranties_overview рассчитывает статус, остаток и шкалу гарантии; UI использует результат сервера. Запрещены бесконечные даты. Добавлены тесты отсутствующей/будущей/нескольких гарантий, включённого дня окончания, FK и границ повторяемости. Удалена дублирующая schema.sql; тесты исполняют обе реальные миграции по порядку.
18. **Evidence:** sharp декодирует JPEG/PNG/WebP, проверяет MIME, лимит 3 МиБ / 25 Мп, отклоняет повреждённые и многостраничные файлы. Лимит снижен с запасом под [ограничение запроса Vercel Functions](https://vercel.com/docs/functions/limitations). Облачный upload/download не проверен.
19. **Проверка живого процесса:** подготовлен npm run test:live. Входит обычными аккаунтами, создаёт дефект, проходит стадии, загружает и скачивает приватный файл, проверяет чужой доступ, приёмку, аудит, историю, изменение источника dashboard и повторный дефект. Скрипт сохраняет маркированные тестовые заявки. Не запускался: нет .env.local и выбранного облачного проекта.
20. **Готовность:** код проходит проверки; весь MVP завершённым не объявляется. Нужны подключение Supabase, обе миграции, seed, test:live и ручной браузерный сценарий. Для публикации ожидается явное согласие на Vercel-аккаунт nerfalmiralti-5552; автоматическая проверка ранее отклонила передачу исходников без такого согласия. Обход не выполнялся.
